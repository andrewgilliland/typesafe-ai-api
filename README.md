# Earnings Call Risk API

A synchronous FastAPI research service that screens one earnings-call transcript
for four risk signals using TypeSafe's Jev model:

- weakening customer demand
- increasing competitive pressure
- management evasiveness
- uncertainty, reduction, or withdrawal around guidance

Alpha Vantage supplies the transcript. Jev evaluates the four semantic questions
and selects supporting transcript chunks. Python applies equal `0.25` weights and
assigns the deterministic risk band: low below `0.33`, medium below `0.67`, and
high at or above `0.67`.

## Prerequisites

- Python 3.14 or later
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- A TypeSafe API key from the [TypeSafe console](https://console.typesafe.ai/)
- An Alpha Vantage API key with earnings-call transcript access

## Setup

```sh
uv sync
```

Create a `.env` file in the project root:

```dotenv
TYPESAFE_API_KEY=your-api-key
ALPHA_VANTAGE_API_KEY=your-api-key
```

Do not commit the `.env` file or your API key to source control.

## Run

```sh
uv run --env-file .env uvicorn main:app --reload
```

Open `http://127.0.0.1:8000/docs` for the interactive API schema. Process health
is available at `GET /healthz` and does not call either upstream service.

Analyze one company and fiscal quarter:

```sh
curl -X POST http://127.0.0.1:8000/v1/earnings-call-risk \
	-H 'content-type: application/json' \
	-d '{"symbol":"IBM","quarter":"2024Q1"}'
```

The response includes the resolved Jev model, each factor's probability and
weight, the weighted overall score, and a risk band. A factor is flagged only
when its probability is at least `0.50`; its evidence is then returned from the
locally held provider transcript rather than generated by the model.

## Validation

```sh
uv run ruff check .
uv run pytest
uv run python -m compileall main.py app tests
```

Tests use fakes and HTTPX mock transports and do not call external APIs.

## Limitations

This is a research aid, not investment advice or an automated trading system.
Version 1 processes one company synchronously, does not persist results, and
depends on Alpha Vantage transcript availability and rate limits. Alpha
Vantage's supplied sentiment is intentionally ignored. Jev probabilities are
semantic judgments, while all arithmetic and thresholds are deterministic
application code.
